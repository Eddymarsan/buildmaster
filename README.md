# BuildMaster

BuildMaster is a responsive construction website built using **HTML, CSS, and JavaScript**. It showcases construction services, projects, and allows clients to submit booking inquiries through Google Sheets.

## Features
- Responsive design for desktop and mobile.
- Construction services and project gallery.
- Booking and contact form.
- Google Sheets integration using Google Apps Script.
- Interactive navigation and website rating system.
- Basic admin login interface.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Sheets
- Google Apps Script

## Setup
1. Clone the repository.
2. Open `index.html` in a browser or use VS Code Live Server.
3. Configure the Google Apps Script URL in `js/script.js`.
4. Deploy using GitHub Pages, Netlify, or Render.

**Note:** Frontend-only admin authentication is not secure for protecting confidential data.
